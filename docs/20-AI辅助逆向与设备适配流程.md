# AI 辅助逆向与设备适配流程

更新日期：2026-11-01。状态：实验与交付规范。目标是把资料、样本与协议假设转化为可复现适配；源码学习、成品分析与实际验收分别记录。

## 1. 实验入口

明确设备所有权、允许分析范围、型号/PCB/固件、供电、通信方式、调试接口与可恢复手段。优先使用公开协议、厂商资料、合法取得的样本和用户授权接口；现有账号凭据不等于可以使用其他客户端专用身份。

公开仓库结构分析采用普通源码研究；对自有或获准的固件、安装包或运行时行为分析，采用与目标匹配的静态/动态工具。AI 工具的输出只作为假设，不能将无法观测的内部实现写成事实。

### 1.1 按资料与接口选择方法

原生产品优先按OS/SDK与器件资料实现产品驱动和IoT Core绑定；标准或公开接口设备优先按合同实现映射；厂商合作设备按实际获准SDK/API开发。资料缺失且具备相应分析条件时，再通过样本和实验补充协议假设。逆向研究是适配手段之一，不能代替接口资格或作为平台运行依赖。

任务开始时记录：接入方向、本地/云路径、接口及许可来源、主体与用途范围、允许操作、凭据来源、适用版本和已知限制。读取与控制、个人研究与商业分发分别判断；购买设备、持有用户账号或采用开源OS不能自动获得其他客户端身份或厂商云访问权。具体生态条件见 [31](31-多生态兼容与开放接入.md)，研究依据见 [02](02-参考项目与技术调研.md)。

## 2. 证据分级

| 等级 | 含义 | 可支持的结论 |
| --- | --- | --- |
| E0 | 官方资料或源码声明 | 声明的接口与行为，不代表实机通过 |
| E1 | 原始帧、日志、波形或运行记录 | 指定环境实际观察 |
| E2 | 对字段、编码和状态的推断 | 待验证假设 |
| E3 | 独立样本回放与负例 | 解析和映射在样本范围成立 |
| E4 | 指定实机和故障验证 | 对应型号/版本的实际能力 |
| E5 | 他人独立复现和持续运行 | 支持发布与交付的更强证据 |

等级描述证据类型，不用简单最高分替代能力范围。只有读取证据的设备不能升级为控制支持。

## 3. 工作流

1. 确认接入路线、接口来源和用途范围；登记实验目标、硬件修订、工具与环境，建立基线与恢复方法。
2. 控制单一变量，采集多个状态、边界、重复、断电和错误样本，记录发生时的实际操作。
3. AI 提出字段、长度、端序、校验、缩放、加密和状态假设，逐条关联证据及可反驳实验。
4. 编写最小解析器与能力映射，保留原始值和未知字段，不靠大量特判掩盖未知语义。
5. 用未参与分析的样本测试，补充截断、坏校验、未知命令和异常值；验证误识别与跨设备串扰。
6. 在实机核对读取、控制、回执、连接和恢复，确认弱身份及单向反馈的限制。
7. 第二名开发者按档案复现；核对依赖许可、接口用途及目标交付条件后，发布映射和支持矩阵。

## 4. 设备档案

档案含稳定 ID、品牌/型号、PCB/固件、芯片与接口、资料来源、采样环境、样本摘要、解析假设、映射修订、模型修订、工具版本、测试结果和未知项，并关联第1节的路线与用途记录。设备密钥和原始客户流量放受控实验区，公共档案只含必要脱敏夹具。

样本拆为分析集与独立验证集。自动回放说明预期观测/错误，不能只判断程序未崩溃。对状态映射检查单位、枚举、时间与质量；对命令检查原操作身份与完成证据。

## 5. Agent 工具合同

提供有界的样本读取、帧解析、差分、回放、模型校验和支持矩阵查询。发射、烧录、擦除或实际驱动硬件的工具声明设备、影响、恢复和授权范围，不能通过任意 Shell/串口写入工具绕过控制。

Agent 缺少实物、密钥、接口资格或安全恢复手段时，记录精确缺口并继续可独立完成的分析；不得生成虚假的实机结果或把推断包装成已验证支持。

## 6. 适配发布门槛

映射/驱动、正式模型引用、正负夹具、协议健康策略、实际反馈等级、依赖许可、型号限制、已验证操作、重连/重启/撤销行为和维护联系人齐全。涉及重依赖时按 [07](07-异构协议与适配器规范.md) 隔离。

接口用途或商业资格未确认时，记录为相应交付缺口；实验结论不自动成为商业兼容声明。固件、接口、条款或认证状态变化时，按受影响能力复验；接口失效或授权撤销后停止对应调用并更新支持状态，保留诊断与恢复说明。

## 7. 质量指标

记录适配耗时、独立复现率、误识别、异常样本覆盖、后续返工和每型号维护工时。AI 生成行数与一次成功解析不能作为适配质量指标。
