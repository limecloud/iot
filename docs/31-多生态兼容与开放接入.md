# 多生态兼容与开放接入

更新日期：2026-11-01。状态：产品与接口路线，尚未实现。生态互通是平台主线，按方向与能力建立证据。

## 1. 两个方向与独立语义

设备接入：将允许访问的既有设备纳入LimeIoT物模型。设备输出：将LimeIoT设备或能力投影至目标生态。平台内部语义由自有模型维护，生态类型与权限留在适配层。

生态内“看见一个设备”、用户授权账号、设备配对和正式商业认证分别是不同事实。多管理员Matter设备加入本平台，不等于本平台可以读取目标生态全部家庭资产。

## 2. 官方资料与当前结论

| 生态 | 可确认的公开事实 | 平台路线与边界 |
| --- | --- | --- |
| Apple Home | [Matter支持](https://developer.apple.com/apple-home/matter/)明确跨生态配对与Matter能力 | 优先Matter Bridge输出；接入经用户允许的Matter设备。传统HomeKit等路线单独验证 |
| Google Home | [支持类型](https://developers.home.google.com/matter/supported-devices)包含桥接设备说明 | 优先Matter；逐类型和控制器测试，不假设任意能力均支持 |
| Google云 | [Cloud-to-cloud](https://developers.home.google.com/cloud-to-cloud)提供设备接入及OAuth授权码流程 | 可选云输出路径，需账号关联、intent映射、测试和认证 |
| 小米/米家 | [官方HA集成](https://github.com/XiaoMi/ha_xiaomi_home)说明云OAuth和指定中枢本地路径，受型号/地区/固件限制 | 作为行为研究，独立平台须取得单独授权、官方合作或使用允许的标准路径 |
| 小米许可 | [LICENSE.md](https://github.com/XiaoMi/ha_xiaomi_home/blob/main/LICENSE.md)将该集成及相关API限于非商业HA用途 | 不能移植其代码、专用身份或API作为本平台实现，需另行明确权利 |
| 小米产品接入 | [官方接入方式](https://iot.mi.com/v2/new/doc/introduction/preparation/access_mode)提供模组/SDK直连与云对云；明确自建App只能控制自有产品，云对云目前仅受邀伙伴准入 | 自有产品输出与导入其他厂商米家设备分开立项；官方产品接入资格不能代替其他产品访问权 |
| 华为 | [HarmonyOS设备官网](https://device.harmonyos.com/cn/)公开Connect伙伴接入、工具与认证路线 | 官方合作为候选；不把OpenHarmony源码等同于商业鸿蒙生态访问权 |
| 百度/小度 | [官方入口](https://dueros.baidu.com/)可访问，但本次公开读取未取得完整现行设备/技能合同 | 先确认开放资格、当前文档和支持类型，再定智能家居技能/厂商合作路线 |

公开页面存在不能证明本平台已获准接入；页面未取得正文也不能证明厂商不存在接口。选定版本和产品后重新核对条款与资格。

Vela/openvela、OpenHarmony 等属于设备系统基础，适配这些系统与取得小米/华为商业生态访问权分别验收。系统范围见 [03](03-总体技术架构.md)，官方接入、企业与产品上线证据见 [02](02-参考项目与技术调研.md)。

## 3. 兼容级别

| 级别 | 证据 |
| --- | --- |
| C0 | 研究候选，路径/资格待验证 |
| C1 | 指定环境可发现和配对 |
| C2 | 正确状态、类型、单位和时间 |
| C3 | 获准控制、结果和未知处理 |
| C4 | 自动化、重连、订阅恢复、撤销与循环防护 |
| C5 | 满足该交付所需认证、许可、质量及商业条件 |

级别按方向、设备类型、型号、地区、固件和控制器分别登记。C5是交付范围结论，不表示该生态所有设备或未来版本通用支持。

## 4. 生态适配器合同

连接记录包含发布者、用户授权、空间、生态、方向、地区、凭据引用、允许资源、映射版本、有效期和撤销状态。发现、选择导入/输出、权限预览、安装和启用分别处理。

每个映射声明核心能力、生态类型/属性、转换、范围、只读/可控、结果证据及不支持项。无法表达的能力不伪装成不对应类型；玩具和机器人可只输出生态支持的基本能力，完整玩法通过平台应用运行。

## 5. 事件、循环与身份

控制进入统一命令用例，状态更新携带来源、原操作及因果链；对回声去重，禁止一条状态在双向映射中反复触发新控制。第三方订阅和本地规则分别检查历史、时效和当前权。

生态云凭据不交给模型或商家应用；Matter Fabric、账号授权和空间主体分别记录。移除连接停止新调用和订阅，保留必要审计，不能默认删除设备本地身份或其他生态连接。

## 6. 实施顺序

先用自有灯光模型完成Matter Bridge至指定Apple/Google环境；随后验证标准Matter接入，再推进具有明确接口资格的小米、华为和百度项目。HA兼容可作为可选适配器，但不得成为本平台接入这些生态的基础运行依赖。

## 7. 验收与宣传

测试配对、类型/单位、读取、控制、部分能力、重连、重启、撤销、凭据更新、多入口并发、回声及权限收缩。跨地区、控制器升级和型号变化需复验。宣传明确实际通过的组合及认证状态，不以协议SDK能编译替代生态兼容。
