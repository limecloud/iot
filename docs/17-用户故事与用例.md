## 2. UC-15：模型调用预算与未知结果

- 参与者：应用、平台模型服务、预算模块、外部提供方。
- 前置：当前空间和应用获准使用指定模态、数据位置与资源预算。
- 主流程：提交有幂等键的调用；冻结允许的模型政策和预算；保存原调用；向提供方发送；记录实际结果和用量；返回受控引用或流。
- 异常：发送后断连标 unknown；支持原操作查询时先核对；不支持查询且可能计费时保留不确定性，不换提供方或换键盲发。预算耗尽停止新调用，已发生用量如实记录。
- 后置：调用事实与商业结算分开，预留、实际用量和释放依据可追踪。相关 FR-25、NFR-02/03。

## 3. UC-16：机器人取消与人工接管

- 参与者：用户、任务服务、网关、机器人本地控制器。
- 前置：有原 task_id 和当前取消/接管权；产品声明支持的操作。
- 主流程：查询当前任务；提交原任务取消请求；设备本地接受并转入停止/安全阶段；回报当前机械状态与任务结果；用户按政策接管。
- 异常：已完成与取消并发时返回原终态；通信断开时取消请求不代表设备已停；急停由本地独立机制生效；恢复连接后查询原任务，不重建旧路线。
- 后置：任务取消阶段与实际设备状态分别可核对。相关 FR-28、NFR-04。

## 4. UC-17：同一能力扩展到教室或健身空间

- 参与者：机构管理员、教师/教练、参与者、应用、设备。
- 前置：建立独立 Space、角色、设备绑定及媒体政策；试点明确参与者和数据范围。
- 主流程：安装经过验证的组合包；绑定教具或运动传感器；配置会话及权限；Agent协助按正式合同运行任务；当前参与者仅访问本会话结果。
- 异常：跨空间媒体或设备引用拒绝；课堂结束或人员退出后收紧新访问；旧会话迟到响应不进入下一堂课；家庭监护关系不自动转为机构授权。
- 后置：平台核心不改设备语义，场景应用拥有教学/运动业务及对应专业判断。相关 FR-24/29。

## 5. UC-18：模型故障后的玩具降级

- 参与者：孩子、玩具、应用会话、模型服务、监护人。
- 前置：产品包定义无模型时允许的本地行为、停止能力和数据政策。
- 主流程：模型超时；停止继续生成外部动作；玩具用预置反馈说明暂不可用；保留允许的按钮、灯光和本地交互；模型恢复后重新核验会话与当前政策。
- 异常：禁止无声改为外部云；过期语音指令不补执行；取消与迟到模型输出并发时丢弃不再有效的工具请求。
- 后置：设备安全与基础交互保持有界，失败原因和恢复状态可解释。相关 FR-14/25/27。

## 6. UC-19：撤销生态连接或转移空间设备

- 参与者：所有者、身份与访问服务、生态适配器、设备。
- 前置：当前所有者证明与精确连接/设备选择。
- 主流程：预览会受影响的访问、订阅和组合；冻结变更；撤销凭据及映射；通知设备或记录离线撤销；在新所有者物理认领后建立新信任。
- 异常：离线设备不能承诺即时抹除旧密钥；按有限凭据与恢复流程处理；不能用新云账户登录直接替代物理转移。
- 后置：新请求和订阅阻断，历史操作按隐私政策保留。相关 FR-10/20/21。

## 7. UC-20：Agent 驱动的验证与发布准备

- 参与者：编码 Agent、开发者、构建系统、模拟器、实机夹具。
- 前置：任务范围、可用工具、固定输入与明确可操作硬件。
- 主流程：读取机器目录和所需章节；加载模型/合同；生成或修改；执行静态、合同、回放；请求必要人工接线；运行实机用例；输出差异、失败、跳过和制品摘要供审核。
- 异常：依赖、硬件或资格缺失保持 blocked/skipped，不能填作通过；不把源码检查当作实机行为；输入发生变化则重新界定证据对应版本。
- 后置：交付报告准确区分设计、实现与验收，符合当前发布权限。相关 FR-15/22/23/30。
