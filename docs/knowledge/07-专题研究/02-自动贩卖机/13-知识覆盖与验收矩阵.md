## 产品验收矩阵

以下是建议的测试范围。通过阈值、样本数量、环境与责任需在项目需求中确定，不能把本表当作现成认证规范。

| 模块 | 代表性条件与故障 | 应留证据 |
| --- | --- | --- |
| 包装与机构 | 最大/最小尺寸、重量、软硬包装、满/少库存、临界装载、包装变更 | 配置、样品、条件、交付结果/损伤、失败与未知数量 |
| 到货判据 | 检测通过/未通过、遮挡、多件、空转、传感器故障 | 原始观测、业务判定、误报漏报及恢复依据 |
| 格口门控 | 门未开、开后未关、错门、取货未完成、维修开门 | 门锁/门磁/内容与订单对应，异常处置与审计 |
| 支付确认 | 验签失败、错金额/币种/商户、重复/乱序通知、通知丢失与主动查单并发 | 原支付标识与订单状态、去重与业务核验记录 |
| 任务执行 | 重复同参、同标识异参、旧身份、过期、队列拥塞和并发 | 任务记录、拒绝原因、物理动作与结果，证明不会盲目补发 |
| 断电/重启 | 意图落盘前后、动作过程中、动作完成与结果落盘之间、换板或恢复备份 | 不同切点的日志、现场事实、恢复策略与人工核对 |
| 退款与对账 | 退款超时、受理/处理/完成/异常、部分交付、渠道对账差异 | 稳定退款标识、最终结果、资金与库存分别处理 |
| 库存与补货 | 错装、重复扫码、并发预占、过期释放、测试出货、盘点与报损 | 商品/货位/批次/版本、差异原因、恢复可售记录 |
| 温控与食安 | 环境变化、开门、装载、断电、温度传感异常、清洁与到期 | 温度分布、产品规则、异常期间停售与放行记录 |
| 现制加工 | 缺料、缺杯、供水/排水异常、清洁未完成、制作中断 | 配方与批次、工艺状态、交付质量和报损处置 |
| 视觉或其他识别 | 相似包装、遮挡、拿后放回、多件/跨货架、包装版本与光照变化 | 数据集版本、事件真值、误判、复核与争议结果 |
| 界面体验 | 多顾客、误触、支付后离开、弱网、取货超时、可访问性 | 角色和使用条件、分段耗时、提示与售后可达性 |
| 网络与权限 | 断连、补传、旧消息、越权、证书/凭据过期、后台失联 | 身份与授权、事件时间和序号、拒绝与恢复记录 |
| 制造与环境 | 装配误差、线束错误、电气/机械风险、运输、EMC/ESD、热与寿命 | 对应版本的产线记录、型式/整机测试与不合格闭环 |
| 版本与售后 | 固件/资源/协议不兼容、升级中断、配置回滚、供应商替代料 | 兼容矩阵、发布基线、工单、备件与追溯 |

## 放行与文档验证的区别

知识库检查仅验证本地链接、格式与图源等文档质量；图形渲染验证仅说明示意图可读。产品放行需要上述机型、环境、交易与制造证据。某一组件通过标准或单项测试，不自动覆盖整机或运营手续。
