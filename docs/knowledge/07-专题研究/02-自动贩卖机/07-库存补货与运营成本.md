# 库存、补货与运营成本

售货设备的经营能力由商品、点位、可用性和现场服务共同决定。联网可帮助采集数据和安排工作，但不会自动解决选品、补货和维修。V07 与 V09 描述了补货、用量和库存工具等商业路线，收益仍需具体运营数据支持。

## 商品、货位与库存

| 数据 | 含义 | 常见错误 |
| --- | --- | --- |
| 商品规格 | SKU、包装版本、条码、售价与必要商品信息 | 包装变更后只改图片，未重测机构或识别模型 |
| 货位配置 | 货道/格口、允许商品、机构参数与配置版本 | 系统显示 A 商品，实际补成 B 商品 |
| 账面库存 | 根据入库、交付、报损和盘点计算的数量 | 将电机动作次数直接当作真实销售数量 |
| 预占库存 | 为尚未完成的订单保留的数量或格口 | 并发超卖，或超时释放与迟到支付冲突 |
| 可售状态 | 综合库存、温度、保质、门与机构健康的判断 | “数量大于零”就继续销售故障或异常商品 |

建议按业务需要保留批次、有效期和供应来源。需要优先销售先到期商品时采用 FEFO（先到期先出）等策略；实际货道能否做到必须用装载规则和结构验证，不能只在数据库排序。

## 补货到恢复营业

1. 补货任务明确点位、设备、货位、商品、批次和建议数量，并记录推荐依据。
2. 补货员进入授权维护流程，处理未完成交易，避免补货开门与顾客取货相互干扰。
3. 核对实物、过期/受损商品、货道/格口映射，记录入货、退货和报损。
4. 完成必要清洁、传感器检查和配置核对；对更换包装或调整机构的货位重新测试。
5. 盘点差异有原因与责任记录，验证可售条件后恢复营业。

测试出货、赠送、内部领用、盗损与正式销售分别记账。退款、库存释放和实物回收也分别处理，不能一键把异常订单恢复为“商品仍在货道”。

## 单台经济模型

先定义设备销售商、点位运营商、商品供货方、支付服务方和维修方各自收入及成本。卖机器赚钱与运营机器赚钱是不同业务，租赁、服务订阅、点位分成和代运营也需分别测算。

| 成本类别 | 组成与证据 |
| --- | --- |
| 一次性工程投入 | 研发、样机、模具、测试/合规、工装、部署和系统接入；以合同与项目成本核算 |
| 单台设备交付 | 机柜、机构、主控/驱动、显示支付、制冷、装配、测试、包装运输与安装；以同配置有效报价比较 |
| 持续经营 | 进货、点位租金/分成、渠道费、电费、网络/软件、补货人工、仓储与配送 |
| 异常与生命周期 | 报损、退款处理、维修、备件、停机、升级与退役；与其他项目去重核算 |

参考计算：每日贡献等于扣除退款后的销售收入，减去已售商品成本、渠道费用、未在前项计算的报损、变动配送及服务成本。每日固定成本可按明确周期分摊租金、固定服务费、设备折旧等。若平均每笔贡献为正且销售组合稳定，盈亏平衡笔数可用“每日固定成本 ÷ 平均每笔贡献”初算，再检查产能、损耗和点位需求约束。

退款、商品损失与收入冲减的会计口径应避免重复计入；融资现金流、税费与会计利润另作完整测算。本专题没有真实报价、客流转化或运营收益数据，不提供回本周期承诺。

## 运营指标的分母

- 交付成功率：先定义按订单、订单项还是设备任务统计，并分别记录失败与未知，不能排除所有异常后声称高成功率。
- 可售率：按整机和货位分别计算，明确计划营业时段、停售及维护是否计入。
- 退款与投诉：以明确订单范围统计，区分未交付、商品质量、误扣款和顾客误操作。
- 补货效率：记录每趟服务时间、缺货时长、报损、错装和库存差异，不只统计后台推荐次数。
- 冷藏/现制质量：监测温控或清洁流程达成情况，不能以“在线率高”替代质量指标。

选点应验证实际人群、替代渠道、营业时段、补货可达性、租金、供电网络与服务责任。单次大促或厂商案例不能直接代表长期需求。
