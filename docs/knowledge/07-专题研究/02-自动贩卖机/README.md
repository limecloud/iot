# 自动贩卖机：从基础原理到量产运营

查证日期：2026-11-02。面向初次接触物联网、自动化和硬件产品的读者，同时按商业量产与持续运营的要求分析。范围覆盖传统商品出货、格口取货、现制/加热和开放自取，包含内部领用与长尾定制；不预设采用 AI、联网或 LimeIoT。

自动贩卖机的核心是将交易授权、商品与库存、物理交付和异常补偿连接起来。**支付成功、设备接受任务、商品实际交付是不同结果。** 能把电机转起来，不能单独证明可以稳定经营。

## 学习与决策路径

初次阅读按 01 基础、02 硬件、03 交易，再阅读 04 屏幕和 05 网络。理解主要概念后，从 10 选择对应交付方式，并结合 08 判断制造责任。准备商业运营时继续读 07 成本与补货、11 场景和 13 验收。

若只是判断与 LimeIoT 是否有关，直接阅读 09：当前缺少售货机需求、适配与实机验收证据，不将平台纳入产品前提。操作系统、图形界面、交易应用和设备管理平台也不能互相替代。

## 关键分支结论

- 螺旋货道和升降机构可以组合，选型以真实商品从装载到取货的完整路径为依据。[V01]
- 格口开门不等于确定单件商品已被取走，门、锁、内容和订单分别核对。
- 现制/加热需要额外工艺、清洁、食品与报损责任，不只是增加一个电机。
- 开门自取的识别与结算顺序不同，预授权也不等于最终扣款。[V09]
- 内部领用已有大型企业提供服务；长尾机会应验证具体痛点，不把大类直接称为“无人竞争”。[V07]
