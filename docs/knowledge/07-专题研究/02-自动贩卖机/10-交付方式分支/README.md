# 商品交付方式分支

本组以“商品如何从储存位置交到顾客”为分类轴。支付、制冷、联网和屏幕可以与各分支组合；制造责任另见[制造路线](../08-制造与量产路线/README.md)。这是工程分析，不是法定设备分类或供应商选型结论。

| 分支 | 成立条件 | 主要工程责任 | 独立文档 |
| --- | --- | --- | --- |
| 货道与送达 | 商品可由指定货位分离并经规定路径送出 | 包装兼容、单件分离、传送、到货反馈与取货 | [货道出货与升降送达](01-货道出货与升降送达.md) |
| 格口与受控领用 | 交付以打开指定空间为主要动作 | 门锁、内容/订单绑定、取货与维护权限 | [格口柜与受控领用](02-格口柜与受控领用.md) |
| 现制或加热 | 交付前需进行加工或调理 | 配方、耗材、清洁、工艺中断与食安 | [现制饮品与加热食品](03-现制饮品与加热食品.md) |
| 开门自取 | 顾客可从共同货架拿取，再识别消费内容 | 入柜授权、拿放识别、结算、争议与损耗 | [开门自取与自动识别](04-开门自取与自动识别.md) |

四类设备都需明确交易授权、完成判据、结果未知和补偿责任；不能把动作成功与交付成功混用。复合机型应对每个订单项注明实际交付路线。

## 储存条件作为独立功能配置

常温设备仍需考虑点位温湿度及商品储存条件。冷藏/冷冻设备还需验证制冷能力、温度分布、开门与装载影响、断电、凝露、排水、传感器误差、有效期与异常商品处置。现制或保温设备另外验证加工和保持过程。

不同食品、包装和经营过程不能使用同一个通用温度阈值。设备测得的空气温度也不必然等于每件商品中心温度。报警之后是否停售、隔离、报损和重新放行，应有产品规则和验证证据。

V05 支持经营规则，V06 仅提供整机安全标准的公开适用范围；两者都不能替代目标商品的完整食安方案。来源见[台账](../12-资料来源与证据边界.md)。回到[专题入口](../README.md)。
