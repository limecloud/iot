# 货道出货与升降送达

货道用于定位和分离商品，后续可通过落货、输送或升降路径送到取货口。螺旋推货与升降送达可能在同一机型中组合，不能只按名称判断优劣。[V01]

## 机构与包装共同设计

螺旋、皮带、推杆等是候选分离/输送机构，是否采用取决于商品形状、摩擦、重心、柔软度、重量、密封和可接受损伤。升降接货可以减少部分自由跌落，但接入、移动和送出仍可能卡住或损坏商品。

| 交付环节 | 工程条件 | 需要记录的证据 |
| --- | --- | --- |
| 装载 | 分隔、方向、间距和补货一致性 | 货道图、商品包装版本、装载规则 |
| 分离单件 | 不空转、不粘连、不多出 | 实际商品与不同库存位置下的测试 |
| 转移与送达 | 路径尺寸、相对位置、接货姿态 | 卡阻、翻转、破损和液体泄漏结果 |
| 取货 | 门与取货区可达、商品不挂住 | 真实用户取出与防夹等风险验证 |
| 结果判断 | 传感证据覆盖预定交付条件 | 检测误报/漏报、失败与未知处理 |

声称“支持零食”不足以判断某个软袋是否适配；容量比较也必须采用相同商品组合与有效间隙，不能直接比较不同包装下的总件数。[V01]

## 失败处理与业务边界

对明确未交付、可能多出、商品停在中间和结果未知分别处理。自动补转一圈属于新的物理风险，必须有机构、检测与任务策略支持，不能作为任意卡货的通用修复方法。

退款后要核对商品是否仍处于原货位、掉落在内部或已经被取出；否则容易在下一单重复交付或错误补库存。

## 制造交付与验收

交付物至少包含机柜/货架与传动图、货道配置、驱动与检测配置、批准包装清单、软件参数、装载维护说明和备件。测试覆盖满/少库存、包装批次、温湿度与运输后的安装误差，并保留成功、失败、未知和损伤的完整分母。

新 SKU、包装尺寸/材质更换、隔板调整或驱动参数变动后，重新核对相关验证范围。采购演示视频不能代替同配置验收。
