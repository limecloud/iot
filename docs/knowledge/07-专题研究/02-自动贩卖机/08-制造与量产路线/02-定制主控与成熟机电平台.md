# 定制主控与成熟机电平台

当现成机柜、货架或交付机构满足商品需求，而控制、交易或界面能力不符合要求时，可以评估自有主控/应用与成熟平台组合。定制主控不必全部自行设计，可委托设计并约定交付和维护责任。

## 接口与责任先行

| 责任域 | 必须取得或形成的资料 |
| --- | --- |
| 机构/驱动供应商 | 电气接口、负载、动作与检测语义、时限、故障与安全要求、允许改装条件 |
| 控制器团队 | 原理图/PCB、BOM、固件、状态机、任务记录、驱动与异常恢复 |
| 业务与支付 | 下单授权、支付确认、出货结果、退款对账、凭据和权限 |
| 整机集成责任方 | 线束、电源、结构、公差、EMC/热、互锁、整机与制造验证 |

保留原 VMC 并使用官方接口，与替换 VMC 直接驱动负载，是责任不同的集成方式。后者通常承担更大控制和验证范围，不能只因接口不方便就默认更换主控。

## 画板的量产意义

专用板可为连接器、尺寸、供电、保护、驱动、检测、成本、装配和产线测试服务。工程样机可以采用模块化连接验证原理；量产应以可靠装配、测试和维护为目标定版，不把临时飞线方案当作最终设计。

既要管理控制板，也要管理线束、货位映射、机构参数、校准、界面资源及支付组件版本。复用成熟机构可以减少部分开发，但原机构配原控制器的历史测试不自动覆盖新系统。

## 验证与成本

覆盖包装与机构、驱动负载、通信故障、传感器异常、掉电恢复、并发支付和实际出货结果。设计测试工装与生产烧录/身份写入流程，验证返工和换板后的状态恢复。

预算包含板卡开发、驱动和协议、整机验证、工装、认证评估、采购库存、返工、现场升级与长期维护。没有目标平台资料时，不给出固定芯片型号、板价和量产交期。
