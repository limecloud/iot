# 整机研发与制造协作

当商品、交付方式、点位环境或关键体验需要现有平台无法提供的结构和工艺时，可以评估整机研发。整机研发指承担系统设计责任，并不等于所有零件自制或自建工厂。

## 完整设计包

| 系统 | 交付物 |
| --- | --- |
| 产品与业务 | 需求、使用者与环境、交付判据、订单/资金/售后责任、成本与维护目标 |
| 结构与机构 | 机柜、货架/格口、传动、取货、维修访问、公差、运输安装及防护设计 |
| 电气与控制 | 电源、保护、主控/驱动、传感、线束、状态机、校准与故障策略 |
| 显示与交易 | 界面资源、输入、支付产品、授权、任务结果与对账 |
| 专业功能 | 制冷、现制、加热或识别对应的工艺、质量、清洁/数据与维护方案 |
| 制造与验证 | BOM、图纸、供应商要求、工装、测试规范、产线记录、追溯及整机验收 |

机械、电气、软件、商品包装和运营流程需要共同收敛。仅有 PCB 布局图、外壳效果图或支付演示，均不足以证明整机可以量产。

## 制造协作与供应链

钣金、塑胶、加工件、PCB、装配、制冷和其他模块可以由不同供应商承担，但关键接口、公差、质量与变更应有统一责任方。开模前确认材料、结构、装配、可维修性与验证状态，记录模具所有权、维护、改模和转厂条件。

对关键件建立供应商变更、替代、停产和备件策略。商品包装变化也可能改变机构与识别条件，应与传统器件变更一样进入影响评估。

## 阶段证据与资金

通过工程、设计与试产验证逐步冻结配置，管理问题、返工和补充试验。试产需要检验工装、人员操作、测试覆盖与实际良率，不能只在少数工程师手中组装成功。

资金计划覆盖研发、模具、测试、首批物料、生产在制、成品库存、现场部署、备件与售后准备金。未来销量和采购单价应由实际订单与有效报价支持，不能用“规模起来就便宜”替代测算。

V01 支持商品和机构共同验证，V05/V06 提供经营及整机安全范围依据；本章设计包与阶段管理为工程建议，尚无目标项目证据。回到[制造入口](README.md)。
