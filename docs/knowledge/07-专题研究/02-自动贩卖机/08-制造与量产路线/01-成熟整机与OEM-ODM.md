# 成熟整机与 OEM/ODM

采购成熟整机、贴牌或委托供应商定制，适用于已有平台能满足商品和交付需求的产品。它可以减少自有开发范围，但仍需明确设计、质量、经营和售后责任；以下为工程采购建议，未推荐具体供应商。

## 先确认交付边界

| 对象 | 合同与验收内容 |
| --- | --- |
| 设备配置 | 机柜、机构、货位、屏幕、支付、制冷、传感器、固件与资源版本 |
| 商品兼容 | 真实包装样品、装载方式、有效容量、成功/失败与损伤判据 |
| 软件与数据 | 后台账号、API 权限、事件、订单和退款责任、数据导出、服务费用与终止处置 |
| 运营与维修 | 点位安装、补货清洁、故障响应、备件、培训、保修边界与物流 |
| 市场与合规 | 对应销售地区和实际配置的资料、测试范围与经营主体责任 |

“支持扫码”“支持 MDB”“可以联网”均需细化成可测试的接口和交易能力。供应商演示的后台功能不能自动算作第三方平台可使用的 API。

## 定制、画板与开模

只改变贴纸、商品和已有界面配置时，可能完全复用硬件。新增支付模块、货道、屏幕或特殊交付功能时，可能需要定制电路、线束、机构或模具，并重新评估测试与合规范围。

采购成熟方案也要管理修改后的完整配置，不能拿原机型资料直接证明所有定制版本合格。模具、设计文件、源代码、工装和停产后的使用权按实际合同分别约定。

## 放行证据与总成本

将批准样机、配置清单、真实商品测试、异常交易、断电/断网、补货维护和验收报告纳入交付。成本比较包含样品、定制开发、最小起订条件、运输安装、持续软件/网络/支付服务、备件与质保，而非只比较机柜单价。

V01 支持按真实商品和完整交付路径测试，V06 提供标准范围线索；目标报价和供应商交付能力尚未核验。共用管理见[制造与量产入口](README.md)。
