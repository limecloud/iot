# 分支 B：定制主控与成熟机电平台

这条路线自主管理控制器和软件，复用合适的泵阀、加热、机架或咖啡机子系统。它可以是商业产品路线；“用了成熟部件”不等于只能做爱好者改装。

准备量产时，自画板的价值经常在于连接与结构一致性、可制造性、产线测试、供应链和维护，而不只是多做一个功能。是否值得自研仍需与成熟方案比较，不能从截图反推具体设计动机。

## 主控开发应覆盖哪些边界

| 子系统 | 要明确什么 | 需要的证据 |
| --- | --- | --- |
| 传感 | 量程、精度、噪声、校准、线束与故障检测 | 数据手册、校准和干扰/故障测试 |
| 功率输出 | 加热、泵阀、电机负载与保护 | 负载条件下的温升、电气、异常和寿命验证 |
| 控制软件 | 状态机、配方、参数范围、互锁与故障恢复 | 需求到测试的映射与整机数据 |
| 电源与通信 | 功耗、掉电行为、抗干扰与可选连接 | 最终线束/外壳中的验证，不能仅测裸板 |
| 结构装配 | 固定、接插件、防呆、维修和隔热防潮 | 装配验证、工艺文件与返修记录 |
| 生产测试 | 烧录、测试点、治具、校准和序列化 | 可执行测试程序、限值、治具版本及结果记录 |

TI 的系统资料支持咖啡机需要感知、控制和界面等模块；制造商 DFM/DFA 资料支持设计应考虑制造能力、元件间距、封装、定位点和极性。[S1、S8] 表中的具体测试计划属于工程建议，不是这些供应商保证提供的服务。

## 从研发文件到可生产版本

量产交付包应包含原理图与 PCB 版本、制造与装配文件、精确料号 BOM、可用替代料、线束与装配要求、固件发布件及哈希、烧录/校准/测试说明、判定限值和追溯字段。

BOM 不是“10k 电阻、一个温度传感器”这种泛称清单。封装、容差、额定值、温度范围和制造商料号会影响制造与性能；替代料需要对应影响验证。PCB 改版、传感器替换和控制参数变化可能互相影响，不能分别私下更新后仍沿用原验收结论。

DFT 是可测试性设计：在设计阶段使板子能被稳定检查，而不是出厂时再靠工程师拿万用表临时判断。ICT、功能测试、校准和整机测试各解决不同问题，详见[统一量产管理](06-工程化量产管理.md)。

## 商业风险与取舍

这条路线比完整整机研发少承担部分零部件设计，但集成责任仍在。采购了成熟泵或加热模块，不能直接推出它在新外壳、水路、控制策略中的整机表现合格。

工程投入包括硬件、固件、整机联调、工装、供应链和验证。若差异化确实依赖控制策略、界面或长期维护权，它可能合理；若成熟主控已经满足需求，自研未必更划算。

已有改装项目只能作为技术参考。能买到某套件，不证明其许可、供货和整机适用性足以支撑商业量产。[S2] 不能把开源演示与正式产品交付混为一谈。

本路线可以完全离线运行。若要联网，先定义产品自己的通信与维护需求；当前没有证据要求加入 LimeIoT。
