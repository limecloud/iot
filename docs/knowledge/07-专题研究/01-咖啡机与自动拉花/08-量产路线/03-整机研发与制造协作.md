# 分支 C：整机研发与制造协作

这条路线对咖啡机作为完整产品的系统设计负责，适用于核心差异涉及热系统、水路、机构、外观或整机工作流程的情况。自研不要求每个零件都自己制造，也不要求自建工厂。

## 需要一起设计的系统

| 系统 | 不能割裂的关系 | 交付物示例 |
| --- | --- | --- |
| 热与流体 | 加热、供水、压力、泄漏、排水、结垢与清洁互相影响 | 系统设计、材料与部件规格、异常工况验证 |
| 电气与控制 | 加热和泵阀负载、接地/隔离、传感与故障策略 | 电气设计、线束、保护策略与测试记录 |
| 机械与结构 | 热膨胀、振动、密封、刚度、装配与维修 | 图纸、公差、样件、寿命和装配验证 |
| 食品接触与清洁 | 水、咖啡、牛奶接触路径及清洗残留 | 材料追溯、适用要求评估、清洁方法与验证 |
| 软件与操作 | 人机界面、任务状态、校准、异常与更新 | 版本基线、使用流程、回归与更新恢复证据 |
| 制造与供应链 | 公差叠加、工装、批次差异、替代料 | 供应商规格、检验与产线控制文件 |

以上是系统工程拆解，不是某款机型的完整安全设计。具体标准、测试限值与抽样要求必须与产品类别、用途和市场匹配，不能套用统一咖啡机参数。

## 开模不等于只做漂亮外壳

结构定型前，应把装配路径、紧固与拆修、散热、泄漏排水、清洁和关键公差纳入评审。注塑、钣金、压铸、机加工等工艺有不同约束；不同零件不一定共用一种制造方式。

开模前需要足够稳定的设计输入，模具试制后还要验证实际成型件。模具修改、材料改变和供应商换工艺都可能改变尺寸、耐温或装配表现，需按影响范围重新验证。供应商能加工出零件，不代表整机已经可以放行。

## 工程组织与外包边界

品牌/产品负责人明确需求与使用边界；系统负责人统筹跨专业接口；电气、机械、固件、工艺和质量分别维护交付物；供应链与制造负责执行及过程记录。人员可以兼任，责任和放行权限要清楚。

外包可以覆盖电路布局、模具、PCBA、部件加工、整机装配或测试服务。外包之后仍需知道：谁维护设计基线，谁批准替代料和变更，谁承担最终产品配置的验证与售后。

## 对资金与规模的影响

资金投入包括研发人力、样件与设计验证、模具工装、试产损耗、采购预付款、库存、实验室与合规活动、售后备件和质量事件准备。单位物料成本只是其中一项；首批能卖出之前就可能产生大量支出。

这条路线给予较高系统控制权，也承担更大工程与交付范围。若差异仅是一个界面或记录功能，需用[分支 A](01-成熟整机与OEM-ODM.md)与[分支 B](02-定制主控与成熟机电平台.md)比较其必要性。

LimeIoT 无法替代上述热、流体、结构与制造职责。本专题没有发现必须将整机研发与它绑定的依据。
