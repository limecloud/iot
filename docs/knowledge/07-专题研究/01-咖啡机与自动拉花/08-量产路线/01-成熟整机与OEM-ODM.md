# 分支 A：成熟整机与 OEM/ODM

这条路线通过已有咖啡机平台开发产品，目标是复用成熟系统，而不是从零设计全部水路、热系统和机构。供应商有量产经验是评估起点，最终配置是否可生产、合规和达到需求，仍需证据。

## 不同合作深度

| 深度 | 实际改什么 | 工程影响 |
| --- | --- | --- |
| 既有整机换品牌或外观标识 | 标识、包装、说明书等 | 核对品牌责任、目标市场、配置及资料一致性 |
| 基于平台局部定制 | 界面、外壳、功能配置、通信等 | 识别受影响的电路、散热、结构、软件和验证范围 |
| 共同开发新型号 | 多个子系统一起变化 | 接近联合研发，不能只按采购成品管理 |

OEM/ODM 在不同公司的定义可能不同。应按设计图纸、固件、模具、采购、测试、认证、备件和变更批准权逐项分工。

## 是否需要自己画板、开模

完全复用已有主控时可以不画新板。若功能或结构变化超出现有板能力，可由供应商改板、委托设计或自己设计，不要求品牌方亲自完成布局。

复用已有外壳可能不新增模具；外观或内部结构变化可能引入新模具或模具修改。开模方案应与装配、热管理、食品接触、清洁和维修一起评审，而不是仅凭外观决定。

## 合作交付物与证据

| 管理对象 | 应形成的交付物 | 可验收的依据 |
| --- | --- | --- |
| 配置 | 型号、BOM、硬件/固件版本和定制差异清单 | 实际送检、试产和出货配置相符 |
| 设计与知识产权 | 设计/软件/模具归属、可用资料及授权边界 | 已签分工与可交付资料，不只口头承诺 |
| 制造与质量 | 进料、过程、出厂测试和批次追溯约定 | 对应批次记录、缺陷与返工数据 |
| 合规 | 目标地区与最终配置的适用性评估和技术资料 | 对应型号/版本的报告、声明及适用性依据 |
| 维护 | 固件支持、备件、保修与停产处理 | 具体版本、供货与响应承诺 |
| 工程变更 | 替代料、固件、模具和工艺变更流程 | 变更影响评审、验证与生效批次 |

例如，欧盟官方说明：以自己名称或品牌销售委托制造的产品，可能被视为制造商，并对整个产品及外购子系统的适用合规负责。它不是“供应商已有证书，所以贴牌后无需判断”。[S10]

## 成本与适用条件

成本包括整机采购、定制工程、模具或工装、验证、最低采购承诺、库存、备件和售后。起订量、独占权、资料交付和改版价格均取决于实际供应商协议，本专题没有报价，不给虚构数字。

适合功能差异可以由成熟平台满足、团队更希望投入品牌与销售或局部创新的产品。若核心差异恰好受制于供应商封闭控制器，应转看[分支 B](02-定制主控与成熟机电平台.md)或[分支 C](03-整机研发与制造协作.md)。

联网、AI 和 LimeIoT 都不是这条制造路线的前提。已有本机功能满足需求时，可以交付独立产品。

依据：制造责任见 S10；其余为工程合作分析与交付建议，未声称存在已签供应商合同。来源见[台账](../07-资料来源与待核验问题.md)。
