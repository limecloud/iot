# 功能分支 E：表面图案打印

这个分支通过打印在饮品表面形成图像，与通过倒奶流动生成图案采用不同工艺。它不能替代浓缩萃取、奶泡制备或饮品风味控制。

Ripples 官方 Ripple Maker 页面描述了在带泡沫饮品及甜点表面打印图案的产品，列出不同型号的单色/多色、杯位与高度识别功能，并介绍专用植物提取物耗材。[S11] 这为表面打印分支提供了厂商公开案例；本次未实测其精度、速度、食品适用性或价格，也没有将它选为供应商。

## 与倒奶分支的区别

| 比较项 | 表面打印 | 自动倒奶 |
| --- | --- | --- |
| 工艺目标 | 在已制备表面呈现图像 | 通过奶与咖啡的流动形成图案 |
| 核心机构 | 打印、定位与相应介质供应 | 倾倒、相对移动与流量控制 |
| 输入依赖 | 杯位、表面状态、图像及适用打印介质 | 奶泡、咖啡底、杯/奶缸和动作 |
| 量产验证重点 | 图像结果、介质适用性、清洁、耗材、堵塞与维护 | 工艺稳定性、运动、倒奶成功率与清洁 |

表格是工艺概念比较，不是具体设备性能保证。“可打印图案”也不能直接等于介质在某个销售市场的食品用途合法或实际饮品上安全适用。

## 进入产品选型前的证据条件

要有具体设备与介质的技术资料、用途和地区适用性依据、材料/耗材追溯、清洁维护说明，以及在目标饮品上的重复测试记录。还应评估耗材供应、闲置后恢复、单位任务成本和故障售后。

上述材料构成该分支进入产品选型与验证的证据条件。厂商称耗材为植物提取物，不等于已完成目标用途、过敏原、销售地区和食品接触条件的适用性判断。

联网是否需要取决于产品是否要接收图片、排队或管理内容；有此需求也不自动意味着需要 LimeIoT。本专题当前不建立平台关联。
