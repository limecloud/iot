# 量产分支与工程化管理

本组以“准备取得或已经取得启动资金，推动商业量产”为分析前提。资金支持定制电路、模具、测试与供应链建设，但不会自动证明设计成熟或产品可放行。下文解释工程路线，不判断某个具体项目已经通过哪些阶段。

## 第一条主轴：谁负责产品设计与制造

| 制造分支 | 设计与供货边界 | 为什么可能画板 | 独立文档 |
| --- | --- | --- | --- |
| A 成熟整机合作 | 采用供应商已有平台，按合同委托生产或共同定制 | 定制界面、通信或局部功能时可能改板；也可能完全复用 | [成熟整机与 OEM/ODM](01-成熟整机与OEM-ODM.md) |
| B 定制主控＋成熟机电平台 | 自己负责主控和软件，复用经评估的泵阀、加热、机构等 | 形成可生产、装配、测试和维护的控制系统 | [定制主控与成熟机电平台](02-定制主控与成熟机电平台.md) |
| C 整机研发 | 对整机系统设计负责，零部件和制造仍可外包 | 主控、功率、界面或运动控制随整机共同设计 | [整机研发与制造协作](03-整机研发与制造协作.md) |

三种分支比较的是设计责任，不是“自己买工厂”与否。自研整机通常也会采购成熟器件和委托加工；OEM/ODM 的商业叫法不能代替合同里的责任划分。

## 第二条主轴：图案成形功能分支

这条主轴可以与 A、B、C 任一制造路线组合，不是另外两种互斥制造路线。

| 功能分支 | 物理过程 | 独立文档 |
| --- | --- | --- |
| D 自动倒奶成形 | 专用机构或机器人控制奶缸/杯的相对运动，通过液体流动形成图案 | [自动倒奶模块与机器人](04-自动倒奶模块与机器人.md) |
| E 表面图案打印 | 在已经制备好的饮品表面打印图像，不能替代萃取与奶泡工艺 | [表面图案打印](05-表面图案打印.md) |

若只需要稳定萃取或自动奶泡，直接采用相应工艺系统，无需加入 D 或 E。原理和区别见[萃取、奶泡与拉花](../03-萃取奶泡与自动拉花.md)。

## 不随分支改变的量产要求

所有分支都读[工程化量产管理](06-工程化量产管理.md)：需求与责任、设计基线、DFM/DFA/DFT、供应链、产线测试、质量追溯、合规、变更、售后和资金。

提供姓名、照片或标志定制的产品，还应读[姓名与图案定制交互](07-姓名与图案定制交互.md)，将输入、预览、任务、杯子核对和执行结果纳入产品验收。

“样机能运行”“供应商能贴片”“准备开模”“取得启动资金”分别只说明一部分条件，不能相互替代。真正的量产放行应有与最终产品配置对应的技术、制造和合规证据。

## 实证与工程分析的边界

- S1–S7 支持咖啡系统组成、专业改装控制、公开接口和厂商功能介绍。
- S8–S9 是制造商公开的 DFM/DFA 与质量流程资料，支持“电路设计之外还要考虑制造和检测”，不证明目标产品已完成这些工作。
- S10 是欧盟官方制造商责任说明，仅适用于相应欧盟规则的解释；不代表本产品的合规评估已经完成。
- S11 是表面打印设备厂商资料，支持存在此产品路线的公开描述，不代替性能与食品适用性验证。
- S12–S14 是该厂商的 App、WebApp 和二维码支持资料，支持已存在的定制内容交互路线，不证明任意中文、离线能力或第三方接口。
- A–E 分支及本组管理表是基于这些事实作出的工程拆解与建议，没有伪装成真实供应商报价或目标工厂记录。
