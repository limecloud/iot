# 平台关联证据与独立产品路线

本次查证没有取得目标咖啡机对 LimeIoT 的需求、可用适配或实机验收证据。**当前不建立必要关联，不将 LimeIoT 纳入产品量产前提，也不推荐为接平台改造专业控制系统。** 证据缺失不能证明永远无关，但足以说明目前不能将关联写成已成立的方案。

## 已有证据与结论边界

| 判断对象 | 已有材料 | 可以得出的结论 | 不能推出的结论 |
| --- | --- | --- | --- |
| 咖啡机本体 | TI 系统设计资料、专业控制项目 [S1、S2] | 传感、加热、泵阀、界面和控制是本体能力 | 这些功能必须依赖 IoT 平台 |
| 奶泡与机器人 | Breville 与 Artly 官方功能描述 [S4、S5] | 存在自动奶泡和机器人倒奶产品路线的公开案例 | 其工艺效果由 LimeIoT 提供或已被本项目验证 |
| 公开联网接口 | Gaggiuino REST/MQTT 文档 [S6、S7] | 该项目提供状态、历史等接口，并描述 Home Assistant 集成 | 任意机型可用、目标产品已接入，或 LimeIoT 已支持 |
| 目标产品需求 | 当前没有取得客户或产品需求材料 | 无法证明需要统一平台 | 记录、协作或远程维护天然构成购买理由 |
| LimeIoT 实现 | 本地架构与进度资料，没有本专题咖啡机驱动及验收记录 | 不能主张已具备该产品接入或量产交付能力 | 目标架构可以代替适配、商业合同或实机验收 |

本地依据：[总体技术架构](../../../03-总体技术架构.md)、[实施计划与进度](../../../24-实施计划与进度.md)。它们用于判断项目边界，不能替代外部咖啡机产品证据。

## 独立产品路线

| 路线 | 产品职责 | 当前分析 |
| --- | --- | --- |
| 完全离线专业设备 | 本机完成控制、工艺、界面与维护流程 | 可作为完整产品路线，不需要另加平台才成立 |
| 原生本地连接 | 产品自己的 Web、蓝牙、USB 或其他已支持接口 | 按具体需求与实现验证，不要求统一平台 |
| 成熟专业生态 | 已存在的配方、记录或管理工具 | 优先比较真实功能与维护边界；Gaggiuino 是公开文档案例，非目标产品选型结论 |
| 新增外部平台 | 增加适配、权限、数据与持续服务责任 | 需要新增收益和实现证据，当前不进入推荐方案 |

开发时使用 AI 辅助整理资料、设计或编程，与运行时依赖 AI、联网或某个平台无必然关系。量产工程管理、生产测试与追溯也无需通过 LimeIoT 才能完成。

## 关联成立的证据条件

如果未来出现明确的跨设备协作、设备管理或服务交付需求，应同时具备以下依据，再重新评估：

| 证据层次 | 成立要求 | 本次状态 |
| --- | --- | --- |
| 产品价值 | 明确使用场景、现有替代方案与可衡量收益 | 未取得 |
| 接口可行性 | 目标型号、固件、协议许可、权限与语义可验证 | 未取得目标产品证据 |
| 实现 | 可审查适配代码、版本与功能边界 | 本专题未实现 |
| 验收 | 实机、正常/异常/断线等测试及结果 | 未执行 |
| 持续交付 | 维护责任、费用、升级兼容、服务退出与售后 | 未建立 |

上述条件用于产品与平台关联的证据评估。缺少关键依据时维持独立产品路线，仓库归属不构成业务关联证据。
