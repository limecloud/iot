# 量产前验证与成本交付

本专题以准备商业量产为前提。原型、工程验证、设计验证和生产验证仍属于产品生命周期，但不能将已准备量产的开发团队默认按低成本爱好实验处理。

## 产品阶段与投入重点

| 阶段 | 主要目标 | 合理投入 | 验收依据 |
| --- | --- | --- | --- |
| 原理与工程样机 | 验证关键技术、工艺与系统可行性 | 现成件、开发板、模拟工具与可修改结构 | 对应实验数据与失效记录 |
| 设计验证 | 接近最终配置满足需求与适用要求 | 定制板、结构、热/流体设计与专业测试 | 受控版本、性能、异常及适用合规证据 |
| 试产与生产验证 | 真实供应链和产线能持续制造 | 工装治具、测试自动化、质量与工艺能力 | 良率、节拍、返工与追溯记录 |
| 持续量产与售后 | 不同批次维持质量且可维护 | 供应链、质量监控、备件、软件和变更管理 | 批次、出厂、现场故障与纠正记录 |

具体职责、放行和版本管理见[工程化量产管理](08-量产路线/06-工程化量产管理.md)。制造责任分支见[量产路线入口](08-量产路线/README.md)。

## 工艺与整机验收

自动倒奶至少区分图案质量、连续成功率、动作耗时、溢出和碰撞、奶温与口感、杯型/奶种适应性、失败重做和清洁维护负担。评分应有明确判据、样本条件与完整记录，避免只选成功展示。

稳定萃取应在定义好的豆、研磨、水、配方、环境与机器配置下测量，并区分控制目标、传感值和最终饮品结果。网络部分单独测响应、更新年龄、丢失与恢复，不能用网络指标代替咖啡工艺表现。

本次无目标产品数据，不给虚构的温控精度、成功率、寿命或试产台数。

## 量产成本结构

| 成本类型 | 纳入范围 |
| --- | --- |
| 单台 BOM 与装配 | 控制、传感、供电、泵阀、加热、机构、外壳、线束与装配 |
| 一次性研发与工装 | 硬件、固件、机械、工艺、模具、治具、验证及改版 |
| 生产质量 | 来料、过程、校准、出厂测试、返工、报废与质量记录 |
| 持续服务 | 清洁耗材、备件、保修、客服、固件与漏洞维护；有云才计对应云成本 |
| 供应与资金 | 采购预付款、交期、最低采购承诺、周转库存与回款周期 |

BOM 是物料清单；价格较低的物料若增加不良、测试或售后，未必降低全成本。有资金后投入专板、模具、治具与专业验证可能合理，仍应通过成本与交付证据评估。

本专题未取得报价、销量、产能或制造良率，不提供精确预算和回本数量。平台接入也不作为默认成本项，只有成立的产品需求才产生相应实现与持续服务成本。

## 查证与验证边界

本次完成公开资料查证、工程分支分析与文档整理，未执行硬件制造、采购、接线、控制或生产验证。公开文档、管理框架、实机报告和工厂记录是不同证据层次；本专题不能充当产品放行文件。
