# 长尾场景研究来源

这份台账支撑[长尾场景机会地图](../04-场景案例/03-长尾场景机会地图.md)和[用户定制与平台能力](../04-场景案例/04-用户定制与平台能力.md)。本轮通过 Computer Use 浏览项目官网、官方仓库和厂商案例库，检索日期为 **2026-11-01**。摘要采用转述，不复制完整文章。

## 1. 这些资料能够证明什么

项目文档能够说明某种需求、设备组合或技术方案已经出现；厂商案例是供应方对部署的描述。两者都不能直接证明中国市场的规模、客户付费意愿、项目毛利或 LimeIoT 的兼容性。

本轮完成的是定性资料研究，没有完成用户访谈、订单统计、竞争产品实测、市场规模测算或第三方部署审计。“大厂不做”“没有竞争”“蓝海”都不能由本台账推出。

| S08 | [ESPHome](https://esphome.io/) | 使用廉价 MCU 与模块构建定制传感器、开关、显示等；配置、无线更新、本地运行及 Home Assistant 连接 | 自制设备已有成熟入口；不能把“低代码做设备”视作 LimeIoT 独有能力 |

| S14 | [Network UPS Tools](https://networkupstools.org/) | 对 UPS、PDU、切换开关、电源、太阳能控制器等提供共同协议和监控管理工具 | Homelab 的电源整合已有专业基础；型号支持仍需按版本与硬件矩阵核验 |

商业案例的发现路径是 Milesight 官网 → [Success Stories 案例库](https://www.milesight.com/company/success-stories/) → `Temperature & Humidity Monitoring` 分类 → 博物馆与食品监测详情页。这里只将已读详情的两项作为案例证据，未将列表中其他标题视为已核验项目。

## 3. 商业复用前仍需核验

| 事项 | 本轮发现 | 后续怎么处理 |
| --- | --- | --- |
| 许可与商用 | iSpindel 首页的 `Lizenz` 段明确写有禁止商业使用的声明；WLED、OctoPrint、Mycodo 等页面也列出各自许可 | 公开可读不等于可以直接复制销售；集成前分别核验代码、固件、硬件、素材和商标的当前授权，本轮未做法律审查 |
| 接口可用性 | 部分项目有 API/MQTT 入口 | 逐项核验版本、鉴权、数据字段、命令结果和错误行为；不能根据“有 MQTT”就宣布兼容 |
| 维护状态 | 个别页面保留较早的更新记录 | 实施前检查对应版本的维护、硬件可得性和安全公告，本轮不作“全部活跃维护”的结论 |
| 地域差异 | 多数案例来自海外或国际社群 | 补充国内社区访谈、采购与安装渠道调查；不同地区的无线电、供电和产品要求分别处理 |
| 成本与收入 | 没有采集统一 BOM、服务费用或财务数据 | 用同一口径记录硬件、网关分摊、安装、云/模型、售后和退换；对真实订单再算毛利 |
