# 资料收集模板

类型：可复制填写的资料条目模板。填写方法见[收集规范](01-资料索引与收集规范.md)。复制到实际主题目录后，用主题与型号命名，不将本模板视为设备验证结果。

## 基本信息

| 字段 | 填写内容 |
| --- | --- |
| 资料标题 | 待填写 |
| 所解决的问题 | 待填写 |
| 主题分类与标签 | 例如：连接协议、音频、设备网关、功耗 |
| 发布方与资料类型 | 例如：厂商参数页、标准原文、工程规范、实验记录 |
| 原始链接与定位 | 待填写原始地址、章节或页码 |
| 发布或更新日期 | 不详时明确写未确认 |
| 实际阅读日期 | YYYY-MM-DD |
| 阅读范围 | 目录、参数页、相关章节或全文 |
| 产品与版本范围 | 品牌、准确型号、固件、地区或协议版本 |

## 原文明确说明什么

用短句准确摘录或转述，并写出对应章节、表格或参数位置。

## 我怎样理解它

用自己的话说明它解决的基础问题，以及如何对应到设备、网关、服务或客户端。把推断标出来。

## 还不能确定什么

列出缺失资料与下一步核对方式。特别区分通信能力、第三方开放接口、本地离线能力和平台实际支持。

## 是否做过验证

| 字段 | 填写内容 |
| --- | --- |
| 实验状态 | 未做 / 已做，并说明范围 |
| 硬件、固件与服务版本 | 待填写 |
| 网络、供电与负载条件 | 待填写 |
| 操作与预期 | 待填写 |
| 观察到的结果 | 待填写；未观察到不能填通过 |
| 失败、限制与后续问题 | 待填写 |

## 关联资料

链接相关入门教程、工程规范与正式证据记录。同一事实在其来源处维护，本条目保留解释与引用。
