## 1. 验证层次

| 层次 | 验证内容 | 不能替代 |
| --- | --- | --- |
| 文档/Schema | 链接、ID、格式、示例和机器目录 | 产品运行 |
| 核心单测 | 类型、权限、状态机、规则、预算与时间 | 真实外部副作用 |
| 合同/模拟 | 多端绑定、工具、假适配器和模拟任务 | 型号实机 |
| 回放 | 样本、负例、映射与独立验证集 | 物理驱动、供电和射频 |
| 集成 | SQLite/Broker/提供方、事务、重启、流与恢复 | 用户完整任务与设备长稳 |
| GUI/TUI/Agent | 角色×任务×宿主版本的完整交互 | 实物和认证 |
| 实机/生态 | 固定型号、固件、控制器、地区与故障 | 其他型号或正式认证 |
| 套件交付 | 固定BOM、烧录、身份、升级、长稳和售后 | 所有未来场景 |

## 3. 非功能门槛

NFR-01 验证独立核心和可替换假适配器；NFR-02 注入事务/发送/执行/回执崩溃；NFR-03 测洪峰、慢消费者、磁盘与推理预算；NFR-04 测跨空间、假身份、撤权和旧凭据；NFR-05 测日志、模型上下文、媒体和导出；NFR-06 核对工具链、SBOM与制品；NFR-07 验证不兼容模型、协议、映射和控制器版本。

## 4. 必测故障

断互联网、断模型、断设备、网关重启、设备掉电、重复/乱序、时间回拨、证书失效、密钥轮换、权限撤销、错误签名、更新中断、未知命令、取消竞态、包越权、提示注入、跨会话迟到结果和硬件替代料变更。

飞行、移动和清洁等产品增加设备本地急停/限位/电量/断连测试。专业场景由应用定义额外标准，平台的通用测试不能代替产品适用的认证或专业验证。

## 5. 证据格式与完成声明

记录需求/用例、源提交、构建输入与摘要、环境、工具/依赖版本、型号/批次/固件、主体/空间、步骤、预期、实际、失败、跳过、原操作引用和证据文件摘要。敏感材料单独受控，公开结果脱敏。

状态为 pass/fail/skipped/blocked/not_run；跳过不计通过，模型生成报告不替代原始结果。只有对应层次和范围满足门槛，才提升当前状态；所有扩展品类与生态分别验收。
