# 身份认证与安全体系

更新日期：2026-11-02。状态：设计基线及已实现子集，当前证据见[实施进度](24-实施计划与进度.md)。平台自研身份和授权生命周期，使用成熟标准协议、密码算法与安全库。

## 1. 信任域

制造身份、空间设备绑定、用户/机器身份、应用委托、生态账号和模型提供方凭据分别管理。证书证明设备密钥身份，不能自动证明其属于某空间或拥有所有动作权。

家庭、企业、教室等以 Space 为隔离边界；成员、服务人员、应用、Agent 和生态桥接身份均有明确范围与期限。家庭监护政策与企业角色策略作为场景政策挂载，不写入通用设备标识。

## 2. 原生设备认领

1. 设备制造或开发时生成唯一密钥，通过受控流程登记公钥；开发身份与正式生产身份隔离。
2. 网关由空间所有者本地初始化，生成独立信任材料和恢复信息；不要求先注册云账号。
3. 用户物理开启有期限认领窗口，核对二维码/指纹与设备随机挑战，证明当前持有设备。
4. 网关验证设备证明和未冲突绑定，为其建立空间凭据和 Topic/能力授权。
5. 设备完成 mTLS、会话与模型握手后进入 ready；配网凭据不作为长期管理凭据。

制造证书、二维码静态内容或同一 Wi-Fi 环境均不足以单独认领。失败和超时关闭窗口，限制尝试并保留脱敏审计。

## 3. 密钥与时间

设备使用芯片支持的密钥保护、Flash Encryption/Secure Boot 配置，网关使用操作系统密钥设施或受控加密存储。具体能力按芯片、板卡和部署方案验证，不能统一假设存在安全元件。

TLS 校验链、用途、主机和有效期；首次缺少可信时钟时，通过物理引导、预置信任公钥和随机挑战获取认证时间，建立单调计时锚点，不使用“关闭证书校验”恢复连接。网关优先具备 RTC，时间不可信时停止依赖可信期限的敏感操作。

轮换保留密钥代次、过渡期限和撤销记录。备份保存所需密钥的加密材料与恢复说明，数据副本不等于密钥可恢复。

## 4. 当前授权

授权至少绑定主体、空间、应用、资源、动作和期限。家庭可有 owner/member/guest/installer 等政策，具体角色由可维护目录定义；最后所有者保护、设备控制和安全管理分别核验。

Web 会话、CLI Bearer、MCP、机器和生态凭据分别校验 audience、用途与 scope。选择 space_id 不授予访问；列表、计数、搜索、媒体、订阅、导出和工具发现也需当前权。

命令受理与实际分发前检查当前政策，必要物理安全条件在设备执行前再次检查。撤销阻止新操作，不能承诺撤回已经发生的机械动作；离线设备依据有限授权有效期和本地撤销同步规则限制旧权。

### 4.1 控制面当前实现

控制面已实现的账户/配对边界见 [正式合同](../contracts/control-pairing.md)：Console/Admin独立HttpOnly会话、受众绑定CSRF、精确Origin/Host；OIDC验证state/nonce/PKCE、签名与当前userinfo，外部故障返回503并保留本站会话，退出仍可撤销本站会话。凭据和verifier加密存储，数据库只保存Cookie摘要；私有凭据轮换使旧会话失效。

控制面配对码120秒，创建新配对取消旧未使用请求，同键恢复不重开窗口。claim证明及事务检查当前所有者、绑定唯一性、期限和重放；撤销不能通过旧claim复活。Rust已实现本地审核、冻结修订批准、Ed25519签名和原绑定核实，家庭PWA及CLI消费同一合同。重启中的网络操作成为unknown，不自动重放；已批准的未知记录阻止另建请求绕过授权。此链路不替代设备物理认领。

机器私钥独立存为0600的PKCS8文件，拒绝符号链接；配对码在SQLite中仅保存绑定空间/原键的AES-GCM密文，不出现在API、事件或模型上下文。安装者预先允许精确控制面origin，网络适配器禁用代理、重定向与自动重试。本地撤销立即生效且不被迟到结果复活；云侧绑定须另行撤销。原密钥与数据库共同备份，NAS恢复缺失配对密钥时拒绝继续。配置和恢复步骤见 [NAS](../deploy/nas/README.md)。

可选出站WSS机器连接已实现，需显式启用。独立连接挑战15秒到期，签名绑定origin、随机连接、云/本地空间、主体和revision；每次心跳复核绑定、owner资格、公钥与scope。云撤销关闭该revision连接，本地撤销停止出站连接；跨连接重放与重复替换均拒绝。连接URL不放Token，拒绝浏览器Cookie/Origin认证；TLS验证与原配对允许的网络边界一致。该层只认证与保活，尚不授予或转发设备动作，见 [正式连接合同](../contracts/control-relay.md)。

## 5. 应用、多模态与组合包

摄像头、麦克风、运动、长期记忆、云模型和对外媒体分享是独立能力。组合包声明所需权限、数据目的、运行位置和预算；安装不自动批准这些权限。

儿童主体采用监护政策和适龄产品内容；课堂/企业按机构授权及人员范围处理。默认只将任务必需数据交给模型；媒体引用短期、有用途限制，不把签名下载地址写入普通模型上下文或公开日志。

## 6. 弱身份和第三方生态

Zigbee 网络密钥、BLE 配对与厂商密钥有各自保证；433 可能没有可靠身份。平台记录 `identity_assurance` 和实际观测质量，不为桥接设备伪造原生身份证书。

生态连接使用用户明确授权、官方允许的客户端与接口，凭据留在对应适配器密钥存储中。禁止复用其他平台专用 client_id 或借用第三方管理员凭据。撤销清理订阅、映射和有效凭据，历史审计按政策保留。

## 7. 威胁与验证

| 威胁 | 控制与负例 |
| --- | --- |
| 假设备/认领劫持 | 物理窗口、密钥持有证明、冲突绑定拒绝 |
| 越权控制/数据泄露 | 跨空间、越能力、过期委托、订阅及字段过滤 |
| 重放与旧会话 | boot/session、消息身份、命令期限和去重 |
| 密钥泄露 | 最小存储、用途隔离、轮换、撤销和日志检查 |
| 模型或内容注入 | 数据与指令隔离、受控工具、无原始凭据 |
| 升级供应链攻击 | 清单与镜像验证、发布权隔离、签名和回滚 |
| 组合包越权 | 不可信代码隔离、依赖锁定、权限差异与执行预算 |
| 恢复复活旧权 | 密钥代次、撤销水位、恢复后重新核验 |

安全事件以空间、主体、动作、操作引用和结果关联，敏感值脱敏。首次可交付套件必须覆盖认领、撤销、轮换、备份恢复和升级失败演练。
