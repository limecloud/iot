# 身份认证与安全体系

更新日期：2026-11-03。状态：设计基线及已实现子集，当前证据见[实施进度](24-实施计划与进度.md)。平台自研身份和授权生命周期，使用成熟标准协议、密码算法与安全库。

## 1. 信任域

制造身份、空间设备绑定、用户/机器身份、应用委托、生态账号和模型提供方凭据分别管理。证书证明设备密钥身份，不能自动证明其属于某空间或拥有所有动作权。

家庭、企业、教室等以 Space 为隔离边界；成员、服务人员、应用、Agent 和生态桥接身份均有明确范围与期限。家庭监护政策与企业角色策略作为场景政策挂载，不写入通用设备标识。

## 2. 原生设备认领

1. 设备制造或开发时生成唯一密钥，通过受控流程登记公钥；开发身份与正式生产身份隔离。
2. 网关由空间所有者本地初始化，生成独立信任材料和恢复信息；不要求先注册云账号。
3. 用户物理开启有期限认领窗口，核对二维码/指纹与设备随机挑战，证明当前持有设备。
4. 网关验证设备证明和未冲突绑定，为其建立空间凭据和 Topic/能力授权。
5. 设备完成 mTLS、会话与模型握手后进入 ready；配网凭据不作为长期管理凭据。

制造证书、二维码静态内容或同一 Wi-Fi 环境均不足以单独认领。失败和超时关闭窗口，限制尝试并保留脱敏审计。

### 2.1 当前离线公钥签发子集

已提供外部P-256/SHA-256 CSR检查与签发：只为NAS配置中已绑定设备签发，需管理者独立核对SPKI公钥指纹。管理端不生成或接收这条路径的设备私钥，CA仍只供离线命令使用。调用CA前耐久保存原CSR、空间/设备、CA、预留序列号及完整请求摘要；丢响应只查原序列号，当前证书有效时可明确导出到新目录，不再签发。

签发前失败与可能已签发分别处理；证据不足保持unknown，同设备新CSR和旧开发签发入口均不能绕过。撤销、签发和备份共用管理锁；只读原查询不恢复当前账本已撤销的凭据。恢复旧NAS/CRL备份可能回退撤销状态，须独立保留并恢复撤销记录；当前没有独立单调锚保证。正式命令、Schema及局限见[外部公钥请求签发](../contracts/device-enrollment.md)。

C3可选本机身份已接入HMAC档位：CA-only配置、可信时钟及无线就绪后，明确USB请求才生成P-256私钥；密钥与证书保存在逐记录硬件HMAC的加密单Blob，提交并重开回读后才输出CSR或使用凭据。导入验证固定CA、单设备CN、本机公钥、仅digitalSignature/clientAuth与有效期；密码库日期校验为构建硬要求。重复pending不换键、重复原证书不写入，不确定写入冻结并重开恢复。固定SDK密码库、NAS签发、真实Broker mTLS/撤销及官方NVS回读已有软件检查；私钥只供内部TLS使用，不提供不可导出安全元件保证。有限物理窗口/挑战、动态归属与自动换证仍未实现，完整原生认领仍未完成；CSR持钥证明不能替代物理持有，静态MAC不检测旧备份回退。

### 2.2 当前受控轮换子集

同设备/空间/CA下通过显式维护入口暂存新P-256键，旧证书保持可用；NAS核对唯一有效前证书的序列号、DER指纹和新公钥，再保存v2意图、原序列号与随机激活挑战后签发。设备验证候选证书并单Blob切换，使用新键签署绑定原请求/空间/设备/新证书/挑战的专用证明；管理端保存证明后才撤销旧证书并更新CRL，必须另行重启Broker。

CA签发、激活和CRL中断均沿原请求恢复，未知和未完成轮换阻止新候选。12组身份检查覆盖两代换钥、过渡凭据、实际SDK签名、旧证书拒绝/新证书可用及中断/完成两种NAS资料备份恢复；产品USB维护只有目标编译证据。该范围不含自动续期、在线签发、过期身份重新认领或CA迁移；切换清除当前记录旧键不保证Flash旧页安全擦除，代次也不防旧备份回退。精确证明和恢复语义见[轮换合同](../contracts/device-enrollment.md#保留旧身份的密钥轮换)。

### 2.3 TV本机身份的设计边界

TV保留含私钥的旧v1/v2材料，另已实现初次本机CSR、公开证书导入及v3密钥引用；AndroidKeyStore的AES-GCM保护材料/请求，EC身份键通过独立端口创建/读取，两者分别验证。原配置与建钥尝试先提交，恢复只读原键/原CSR，证书与完成状态同事务保存；不确定结果冻结并重开核对，缺钥不补建。已有PEM或有效本机身份不能走初次签发替换；受控双键切换、耐久激活证明、原管理结果核对及已撤销旧键的明确清理已有软件实现，实际Android与完整生命周期仍待完成。正式边界见 [设备合同](../contracts/tv-agent.md#初次本机身份与原请求恢复)，当前软件与端上范围见 [24第4.33节](24-实施计划与进度.md#433-tv过期身份维护与持续有效期软件闭环)；完整路线见 [34第5.5节](34-电视终端与AndroidTV接入.md#55-本机身份接入与保留原记录的换钥方案)，取舍见 [ADR-26](26-架构决策记录与风险.md)。

旧键清理须同时具备原轮换、已保存证明、管理完成观测和固定CA签名的有效CRL，管理JSON不能独立授权删除。先提交原清理意图与批准时刻，再核对实际旧键公钥并删除；不确定结果重开后沿原决定恢复，当前/候选键受保护。旧v1记录不猜alias，旧PEM无本机旧键；不自动清理，不保证旧页/备份擦除或防旧备份回退。精确时效、状态及容量边界唯一维护在 [清理合同](../contracts/tv-agent.md#已撤销旧密钥的受控清理)。

各终端复用稳定身份、固定CA、原请求恢复与撤旧语义，按实际OS实现密钥和耐久存储；不统一存储布局或假设同等硬件保护。TV须单独处理KeyStore与SQLite之间的崩溃恢复，换钥保留原授权和命令边界；不能以C3的软件结果或TV的AES安全组推导该流程已通过。TV过期维护已有下节的软件证据；C3的明确维护及原CSR恢复软件范围见 [24第4.34节](24-实施计划与进度.md#434-c3过期身份维护与原csr恢复)。实际Android、C3芯片/USB与掉电、物理认领、自动续期及CA迁移仍分别交付，不能跨终端继承验收。

## 3. 密钥与时间

过期叶证书的管理端恢复已有独立离线`recover-csr`：固定原设备/空间/CA，独立核对旧证书和不同新公钥，旧证书须真实到期且未撤销，CA仍有效；歧义或未知/未完成候选拒绝。v3意图将恢复用途纳入摘要，复用新键激活、撤旧及原操作恢复，不恢复旧证书权限或放宽TLS时间校验。正式规则见 [恢复合同](../contracts/device-enrollment.md#过期身份的受控管理端恢复)，软件证据见 [24第4.31节](24-实施计划与进度.md#431-过期身份恢复的管理端合同与软件闭环)。TV/C3端侧维护、密钥丢失、重新认领、CA迁移和自动续期仍独立交付。

当前设备静态存储子集已有可选C3 HMAC NVS档位。配置、命令回执和OTA日志使用同一受控存储适配器；初始化前认证设备/空间绑定，要求已预置HMAC_UP且读/写/用途均受保护，只读取现有派生方案，失败不回退明文，不调用eFuse写入或密钥生成。离线准备只输出加密配置、绑定区和严格回执，见[正式合同](../contracts/device-storage.md)。这不是原生设备认领完成证据，也不提供Secure Boot、分区整体认证或旧备份回退检测；制造硬件状态按用户要求跳过。

设备使用芯片支持的密钥保护、Flash Encryption/Secure Boot 配置，网关使用操作系统密钥设施或受控加密存储。具体能力按芯片、板卡和部署方案验证，不能统一假设存在安全元件。

TLS 校验链、用途、主机和有效期；首次缺少可信时钟时，通过物理引导、预置信任公钥和随机挑战获取认证时间，建立单调计时锚点，不使用“关闭证书校验”恢复连接。网关优先具备 RTC，时间不可信时停止依赖可信期限的敏感操作。

轮换保留密钥代次、过渡期限和撤销记录。备份保存所需密钥的加密材料与恢复说明，数据副本不等于密钥可恢复。

### 3.1 维护读取与当前执行资格

以下是端侧维护的设计与验收要求。维护读取只用于核对已保存的身份和原请求，可以识别已过期叶证书；固定CA仍须当前有效，叶证书不得尚未生效，签发、设备归属、用途、公钥与实际持钥均须核对。密钥丢失、CA失效、错绑或未知记录进入诊断，不能自动转成过期恢复。维护流程不通过更改时钟或关闭TLS日期检查完成。

维护视图不成为连接凭据或动作许可。连接及重连始终要求当前有效的证书；已建立的长连接也须在消费控制请求及调用副作用端口前核对有效期，循环或心跳负责及时退出失效连接。不能只禁用界面按钮，或假定TLS握手成功后会在证书到期时自动断线。失效阻止新动作，可能已发生的动作按原命令保留结果或unknown，不能宣称已撤回。

停止连接后，经明确批准才可推进恢复；保留诊断、原请求核对及撤权入口，维护模式不增加控制授权。已有未完成换钥必须恢复原ID、密钥、CSR和管理意图；新用途不能覆盖原签发、挑战或未知结果。具体TV流程与验证矩阵见 [34第5.5.8节](34-电视终端与AndroidTV接入.md#558-过期身份维护与原请求连续性)。TV已有维护读取、原请求转换与持续有效期的软件实现；实际Broker及宿主证据见 [24第4.33节](24-实施计划与进度.md#433-tv过期身份维护与持续有效期软件闭环)，不推导为实际Android、C3或其他终端均已通过。

### 3.2 C3运行期凭据窗口

ESP适配器在启动MQTT前验证固定CA、设备CN、用途及本机密钥匹配，并冻结叶证书和CA的公开有效日期。组件构建强制启用密码库日期校验，默认开发档位也受此约束；缺少日期能力时拒绝启动。接收、排队消费、发布、属性驱动提交及OTA当前会话检查共用凭据窗口；可信时钟失效或任一证书超出窗口后，当前实例保持拒绝，工作线程停止MQTT，不因时间再次可用而自动恢复。

MQTT库的自动重连关闭，由工作线程每次核对当前凭据后明确重连，失败沿原5秒间隔重试；断线或门禁失效使原连接代次失效。门禁拒绝不清理命令或OTA日志，不把未上报结果作为重新执行理由。恢复须先由独立身份维护流程取得有效凭据，再重新启动适配器。

验证入口为`npm run test:firmware:credentials`，先以`test:firmware:identity`准备固定SDK宿主密码库。当前专项验证真实SDK的身份检查、可信时钟失效锁定、叶证书和CA真实墙钟到期；ESP32-C3目标编译单列，不将凭据窗口检查推导为完整ESP MQTT任务、射频或实机通过。

`npm run test:firmware:runtime`另已通过3条生产适配器宿主旅程：真实mTLS/Broker/Rust网关/SQLite，分片重组、队列及有效期内受控重连；叶证书到期、CA到期和可信时钟失效后，已耐久命令及跨到期排队请求均无新增驱动效果，当前实例锁定、停止传输且不再发布或重连。迟到连接/订阅/数据事件与发布、驱动及OTA当前资格门禁分别拒绝。FreeRTOS、文件NVS、灯驱动和OTA端口为夹具，传输使用libmosquitto/OpenSSL；不代表实际ESP MQTT/ESP TLS调度、OTA安装与日志恢复、换证后重开或实机通过。证据见[运行期集成记录](24-实施计划与进度.md#c3适配器运行期软件集成)。

生产worker的代次、停止与重连边界另由`npm run test:firmware:dispatch`验证，见 [24第4.36节](24-实施计划与进度.md#436-c3生产worker代次与停止重连边界)。新连接建立但旧工作尚未消费时，发布、驱动和OTA当前资格均须拒绝旧上下文；失效前入队的握手在真实叶证书或CA到期后不得执行。停止失败继续重试，成功后停止重复调用；仍有效的身份在两次连接失败后按真实5秒间隔重试。该入口使用确定性平台夹具与实际密码库，不继承真实Broker或硬件的证明范围。

换证后的同进程凭据接线与新进程连续性由`npm run test:firmware:recovery`独立验证，见 [24第4.38节](24-实施计划与进度.md#438-c3同进程身份与跨进程执行记录恢复)。实际C身份/存储向生产适配器供给有效凭据，宿主TLS直接消费内存中的证书与密钥；不经工具导出私钥。原实例真实到期后锁定，明确NAS维护沿原CSR完成签发/激活/CRL，新进程保留原日志并创建新boot/session。命令原结果和未决意图不重放，恢复的未决OTA保持占用，不因新身份而重新安装。当前2条常规软件旅程通过；宿主NVS/eFuse/HMAC根、FreeRTOS及产品/安装端口为夹具，恢复故障、ESP原生运行与硬件保护另验。

## 4. 当前授权

授权至少绑定主体、空间、应用、资源、动作和期限。家庭可有 owner/member/guest/installer 等政策，具体角色由可维护目录定义；最后所有者保护、设备控制和安全管理分别核验。

Web 会话、CLI Bearer、MCP、机器和生态凭据分别校验 audience、用途与 scope。选择 space_id 不授予访问；列表、计数、搜索、媒体、订阅、导出和工具发现也需当前权。

命令受理与实际分发前检查当前政策，必要物理安全条件在设备执行前再次检查。撤销阻止新操作，不能承诺撤回已经发生的机械动作；离线设备依据有限授权有效期和本地撤销同步规则限制旧权。

### 4.1 控制面当前实现

控制面已实现的账户/配对边界见 [正式合同](../contracts/control-pairing.md)：Console/Admin独立HttpOnly会话、受众绑定CSRF、精确Origin/Host；OIDC验证state/nonce/PKCE、签名与当前userinfo，外部故障返回503并保留本站会话，退出仍可撤销本站会话。凭据和verifier加密存储，数据库只保存Cookie摘要；私有凭据轮换使旧会话失效。

独立控制面CLI使用Console会话，不接受本地网关Bearer。私有实例从受控凭据文件登录；Console本人经Origin/CSRF校验可显式创建最长一小时的CLI子会话，材料不含父Cookie或外部Token。子会话的加密凭据引用原父会话，每次动作重查父会话、主体及当前外部身份；父登录退出/到期/撤销后失效，禁止子会话再次委派和Admin导出。子退出仅撤销自身，提供方503时保留会话，永久身份拒绝则拒绝后续使用。CLI材料保存在本人0600文件和0700目录，拒绝符号链接、宽松权限和覆盖已有秘密；stdout、原操作日志和模型上下文不含秘密。合同见 [控制面OpenAPI](../contracts/control.openapi.yaml)，使用见 [CLI](../packages/cli/README.md)。

控制面配对码120秒，创建新配对取消旧未使用请求，同键恢复不重开窗口。claim证明及事务检查当前所有者、绑定唯一性、期限和重放；撤销不能通过旧claim复活。Rust已实现本地审核、冻结修订批准、Ed25519签名和原绑定核实，家庭PWA及CLI消费同一合同。重启中的网络操作成为unknown，不自动重放；已批准的未知记录阻止另建请求绕过授权。此链路不替代设备物理认领。

原生云授权后端、Console确认页与Swift/Kotlin独立授权/读取/远程库已实现，App云界面已接入源码；Android APK和宿主状态检查通过，iOS整包及两端运行待验收。原生端持有独立原随机键和PKCE verifier，系统浏览器本人登录后输入手机授权码明确批准；原键/码/材料不进入URL、模型或浏览器存储。批准与子会话同事务提交，轮询只读原加密材料，响应丢失或重启不重新签发；取消同事务撤销，迟到批准不能恢复。最长一小时的子会话复用CLI父登录/当前身份检查，不能再委派，也不增加网关执行权。五分钟领取窗口、错误码次数、配额、限流和恢复要求见 [原生授权合同](../contracts/control-native.md)。

两端`ControlClient`要求安全存储接口必填，原证明先落盘再请求；云记录使用独立命名空间，不覆盖NAS本地会话。材料经origin、Console受众、当前主体/CSRF和期限核实后保存，界面只取得不含Token的状态。401清理材料、提供方503保留，退出不先调用userinfo，且只撤销子会话。远程完整请求及发送标记先保存，旧键仅查询，退出保留操作；主体/空间和设备结果证据须匹配。真实库已通过HTTPS/WSS、临时MySQL、MQTT模拟设备及Chromium联调，含未受信CA拒绝、丢响应/重启恢复且不重复发送；手机Keychain/Keystore、系统浏览器和App生命周期仍待验收。

机器私钥独立存为0600的PKCS8文件，拒绝符号链接；配对码在SQLite中仅保存绑定空间/原键的AES-GCM密文，不出现在API、事件或模型上下文。安装者预先允许精确控制面origin，网络适配器禁用代理、重定向与自动重试。本地撤销立即生效且不被迟到结果复活；云侧绑定须另行撤销。原密钥与数据库共同备份，NAS恢复缺失配对密钥时拒绝继续。配置和恢复步骤见 [NAS](../deploy/nas/README.md)。

可选出站WSS机器连接已实现，需显式启用。独立连接挑战15秒到期，签名绑定origin、随机连接、云/本地空间、主体和revision；每次心跳及动作结果复核绑定、owner资格、公钥与scope。云撤销关闭该revision连接，本地撤销停止出站连接；跨连接重放与重复替换均拒绝。连接URL不放Token，拒绝浏览器Cookie/Origin认证；TLS验证与原配对允许的网络边界一致。固定远程动作另带短期委托并经当前本地授权，连接成功不自动取得动作权限，见 [正式连接合同](../contracts/control-relay.md)。

远程commands.write只允许创建本来源命令及查询其原remote_id，不开放任意本地command_id或列表。机器授权来源保存在本地原命令中，进入dispatched前再次检查撤销与期限；重启unknown不重放。云端MySQL先保存原发送意图，再写WSS；原键恢复及显式核实不能续期或创建第二条命令。Admin身份不具备家庭远程权限。

## 5. 应用、多模态与组合包

摄像头、麦克风、运动、长期记忆、云模型和对外媒体分享是独立能力。组合包声明所需权限、数据目的、运行位置和预算；安装不自动批准这些权限。

儿童主体采用监护政策和适龄产品内容；课堂/企业按机构授权及人员范围处理。默认只将任务必需数据交给模型；媒体引用短期、有用途限制，不把签名下载地址写入普通模型上下文或公开日志。

## 6. 弱身份和第三方生态

Zigbee 网络密钥、BLE 配对与厂商密钥有各自保证；433 可能没有可靠身份。平台记录 `identity_assurance` 和实际观测质量，不为桥接设备伪造原生身份证书。

生态连接使用用户明确授权、官方允许的客户端与接口，凭据留在对应适配器密钥存储中。禁止复用其他平台专用 client_id 或借用第三方管理员凭据。撤销清理订阅、映射和有效凭据，历史审计按政策保留。

### 6.1 电视终端与用户控制身份

Android TV Agent 使用本设备身份，只接收自身命令和上报自身状态；网页/手机使用当前用户会话。电视大屏另作为用户控制客户端时隔离两类凭据，不把空间所有者 Token 写入设备接入进程。原生设备证书与 ADB 授权是两种绑定，不能互相代替。

ADB 私钥由网关受控存储；归并 Agent 与适配连接需要当前所有者批准和设备侧证明。撤销任一执行路径后停止该路径的新命令，保留原操作核实；不能自动换另一端恢复执行权。具体能力和 Android 权限边界见 [34](34-电视终端与AndroidTV接入.md)。

## 7. 威胁与验证

| 威胁 | 控制与负例 |
| --- | --- |
| 假设备/认领劫持 | 物理窗口、密钥持有证明、冲突绑定拒绝 |
| 越权控制/数据泄露 | 跨空间、越能力、过期委托、订阅及字段过滤 |
| 重放与旧会话 | boot/session、消息身份、命令期限和去重 |
| 密钥泄露 | 最小存储、用途隔离、轮换、撤销和日志检查 |
| 模型或内容注入 | 数据与指令隔离、受控工具、无原始凭据 |
| 升级供应链攻击 | 清单与镜像验证、发布权隔离、签名和回滚 |
| 组合包越权 | 不可信代码隔离、依赖锁定、权限差异与执行预算 |
| 恢复复活旧权 | 密钥代次、撤销水位、恢复后重新核验 |

安全事件以空间、主体、动作、操作引用和结果关联，敏感值脱敏。首次可交付套件必须覆盖认领、撤销、轮换、备份恢复和升级失败演练。
