# LimeIoT 工程文档

更新日期：2026-11-01。状态：设计基线；除文档和示例外，产品能力均待实现。项目采用 Apache-2.0，许可范围见 [25](25-开源许可生态与商业化.md)。

## 1. 阅读方式

Agent优先读取根 `llms.txt`、`catalog.json` 和 `requirements.json`，按任务获取具体规范与示例。产品与规划阅读 01、03、17、24、29；设备开发阅读 05、06、08、12、13；网关开发阅读 04、07、09、10、14；客户端及 Agent 阅读 11、15、16、27；硬件和适配阅读 19、20、30；验收和交付阅读 18、21、22、23、28。

本套文档学习 Lime Cloud 的编号目录、领域事实归属、合同驱动、多端共用用例、原操作恢复、需求追踪和真实验收方法。文档内容围绕 IoT 重新设计，未复制 Lime Cloud 的商业领域、部署限制或门户数量。

## 2. 设计基线

| 类别 | 内容 | 状态 |
| --- | --- | --- |
| 产品 | AI-first 智能物联与能力组合平台，家庭/玩具首批，向企业/教室/健身扩展 | 用户已确认 |
| 核心 | 自研物模型、MQTT 应用报文、ESP-IDF SDK、Rust 网关、事件总线、设备状态机、DSL、身份与 OTA 管理 | 用户已确认 |
| 边界 | 外部组件经适配器隔离，基础运行不深度依赖 HA/ESPHome/zigbee2mqtt | 用户已确认 |
| 网关 | 轻量 Linux 版与 N100 算力版，共用核心 | 用户已确认 |
| AI | 统一文字/视觉/图像/语音服务，提供方独立；Agent优先的工具和GUI/TUI | 用户已确认 |
| 商业 | 开发者与商家发布能力组合、设备套件和技术服务 | 用户已确认 |
| 名称 | LimeIoT / 青柠物联，仓库为 limecloud/iot | 项目基线 |
| 工程 | Rust/Tokio/SQLite；云端 Go/Gin/MySQL；React/TypeScript/PWA | 工程基线 |
| 许可 | Apache-2.0 | 项目基线 |

自主可控指核心应用与生命周期可独立演进，不承诺芯片 BootROM、无线二进制组件或厂商 NCP 栈全部开放。边界分析见 02/07/26。

## 4. 状态与变更规则

状态词统一为：设计草案、待实现、实施中、待验收、已验收、阻塞。设计完成不等于实现；静态示例通过不等于设备接入；单型号通过不等于协议全兼容；实验环境通过不等于可量产。

需求变化更新 01，领域归属更新 04，协议更新 05/06/07/16，安全更新 12，升级更新 13，决策更新 26，验收范围更新 23；当前进度只在 24 维护，型号证据只在 30 维护。跨文档通过链接引用，不维护多份可编辑事实。

示例中的 ID、时间和产品为虚构；内容摘要可用于一致性校验，不能证明签名可信或设备真实存在。`contracts/`、产品源码和 `make` 目标尚不存在时，只以代码字体表示目标路径，避免形成失效链接或可运行承诺。
