# 网关进程启停

本合同定义Rust应用进程的资源生命周期。OS、HTTP、MQTT与协议子任务由运行时拥有，领域核心不处理系统信号。机器能力和数据库版本不因进程关停改变。

## 启动与信号

网关完成配置、存储恢复、HTTP监听绑定及系统信号注册后，再启动MQTT、已配置的协议集成、规则计划、媒体和远程连接任务。启动失败不留下已启动的设备任务。Unix同时接受SIGINT与SIGTERM；其他平台使用Tokio的Ctrl+C事件。

收到第一个关停信号后发布本进程不可逆的watch状态，并记录`gateway.stopping`及信号名称。该状态不写业务事件表，不参与空间/设备授权，也不跨重启保存。

## 排空与资源释放

HTTP停止接受新连接。现有SSE订阅结束正文，不制造新业务事件、游标或命令回执；已有`gap`、会话撤销和耐久游标规则不变。客户端重连后按原游标读取，进程重启后的浏览器会话须重新登录。

HTTP中的在途请求最多等待3秒。期限内完成记录`gateway.stopped`且`http_drained=true`；超过期限记录`gateway.http_drain_timeout`，结束排空并以`http_drained=false`明确保留未完成请求事实。正常计划停机可以返回退出码0，但不能据此推断所有请求或设备操作完成。外部调用者按原操作编号查询，不因连接断开重发。

MQTT接收与派发共用一个父future。关停取消网络循环、规则计划、媒体及远程连接任务；各协议集成的父任务取消并等待全部子任务。ZNP在途读取取消后关闭传输并执行串口RAII恢复，再完成进程退出，不等待原30秒读取期限。网关通过JoinSet回收任务，不留游离派发器。

取消不会把已发出的设备动作撤回，也不会伪造confirmed/failed。原Store事务、发送前耐久意图、结果未知与恢复不补发规则继续生效。强制SIGKILL、供电中断和进程外模型服务不在此关停保证内；同步存储/系统调用不可被Tokio计时器抢占，3秒是HTTP异步排空预算，不是所有硬件和故障条件下的进程退出承诺。

## 运行记录与验证

日志仅含事件名称、信号和排空结果，不含Token或来源会话。NAS当前Compose的15秒停止宽限保留，容器外层supervisor和Linux串口须独立验证。

```sh
npm run test:gateway:shutdown
```

专项使用macOS伪终端NCP、真实Rust网关、SQLite和MQTT模拟灯。两条旅程分别保持浏览器会话和Bearer的SSE，等待已到达NCP的30秒无响应读取，再发送SIGINT或SIGTERM；SIGTERM另保留未完成HTTP请求体。验证4秒以内退出码0、服务端正常结束SSE、进程退出后TTY立即恢复、串口可重开、重启保留原confirmed命令且不重放、旧浏览器会话失效和未完成请求零受理。该软件结果不替代NAS容器、Linux串口、OTA安装或实机验收。
